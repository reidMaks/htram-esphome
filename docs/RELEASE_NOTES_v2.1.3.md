# HTRAM Release v2.1.3

## Огляд релізу (Release Overview)
Реліз `v2.1.3` оновлює екран діагностики сопроцесора GD32 (fallback screen), який активується під час оновлення прошивки ESP32, початкового завантаження або при втраті зв'язку між чіпами. На екрані тепер відображається динамічна актуальна версія GD32 (`1.3.2`), вичерпна статистика пам'яті (Flash/ROM та SRAM GD32, статус SPI Flash і графічних асетів), а також автономна телеметрія датчиків CO2, температури, вологості та живлення, забезпечуючи високу читабельність у межах круглого безеля.

---

## Основні зміни (Key Features & Improvements)

### 1. Новий екран діагностики GD32 (Readable Fallback Screen)
- **Динамічна версія**: Замінено застарілий захардкоджений рядок `"HTRAM GD32 1.0.0"` на динамічне форматування версії з `GD32_FW_VERSION` (`HTRAM GD32 1.3.2`).
- **Статистика пам'яті GD32 та сховища**:
  - `ROM  : <розмір>K/64K (<відсоток>%)` — реальний обсяг зайнятої внутрішньої Flash-пам'яті GD32 з точністю до десятих.
  - `RAM  : <розмір>K/8K (<відсоток>%)` — обсяг статично виділеної SRAM GD32 (.data + .bss).
  - `SPI  : W25Q32 4MB [OK]` — детекція та статус зовнішньої Flash-пам'яті Winbond 25Q32.
  - `ASSET: <кількість> ICONS (<розмір>K)` — валідація контейнера графічних асетів у блоці 4 SPI Flash.
- **Автономна телеметрія сенсорів**:
  - `CO2  : <ppm> PPM` — показники концентрації CO2 з підігрівом (`WARMING UP...`) та кольоровою градацією (зелений < 1000, жовтий < 1500, червоний >= 1500 ppm).
  - `TEMP : <температура> C` — температура з сенсора SHT30.
  - `HUM  : <вологість> %RH` — відносна вологість з сенсора SHT30.
  - `BATT : <напруга> MV [CHRG|USB|BATT]` — напруга акумулятора та статус джерела живлення.
- **Системний аптайм**: Лічильник `UPTIME: <сек>S` у нижній частині екрана як індикатор працездатності coprocessor.
- **Візуальна оптимізація та безпека безеля**:
  - Чітке вирівнювання за двома колонками (лейбли $x=32$, значення $x=88$), акуратні роздільники темного кольору.
  - Повне дотримання геометрії круглого дисплея 240×240 (всі елементи розташовані в безпечній зоні без обрізання країв).
  - Статична частина малюється один раз при вході в режим, а сенсори оновлюються щосекунди без мерехтіння.
  - Розширено мінімальний шрифт `font8x12` відсутніми гліфами (`%`, `(`, `)`, `[`, `]`, `K`, `L`, `Q`, `X`, `Z` тощо).

### 2. Підвищення версій компонентів
- **ESPHome Firmware**: `v2.1.3`
- **GD32 Coprocessor Firmware**: `v1.3.2` (`0x0132`)
- **Graphic Assets Container**: 47 активних асетів (без змін)
