# HTRAM Release v2.3.0

## Огляд релізу (Release Overview)
Реліз `v2.3.0` присвячений кардинальному виправленню та стабілізації вимірювань температури і відносної вологості. Усунуто некоректну динамічну модель самонагріву в співпроцесорі GD32, яка призводила до штучних стрибків показів при перемиканні живлення (USB / батарея) та спотворення кліматичних даних. Прошивка GD32 переведена на прозору передачу сирих фізичних даних сенсора SHT30, додано діагностичні сутності в Home Assistant та впроваджено зручне візуальне калібрування у веб-інтерфейсі.

---

## Основні зміни (Key Features & Improvements)

### 1. Виправлення логіки компенсації температури в GD32
- **Проблема**: Попередня прошивка GD32 містила динамічну модель компенсації, яка віднімала 6.5 °C на батареї та додаткові 5.0 °C при підключенні USB. При відключенні кабелю USB фільтр релаксації швидко прибирав 5 °C поправку швидше, ніж алюмінієвий корпус міг охолонути, через що температура раптово «підстрибувала» на 2–3 °C вгору, а на USB була заниженою на ~3 °C відносно кімнатної.
- **Рішення**: З драйвера `firmware/gd32/src/sensors.c` повністю видалено динамічні формули самонагріву та релаксаційний фільтр. Співпроцесор транслює **100% сирі фізичні дані** сенсора SHT30 (`t_raw`, `h_raw`) через бінарний UART протокол.

### 2. Діагностичні сенсори сирих показів
- У ESPHome додано нові діагностичні сенсори:
  - `Raw Temperature` (`sensor_temp_raw`)
  - `Raw Humidity` (`sensor_hum_raw`)
- Сирі покази транслюються в Home Assistant та віддаються у JSON-відповіді REST API `/api/status` (`raw_temp`, `raw_hum`).

### 3. Прозоре калібрування та калібрувальний зсув за замовчуванням
- У веб-інтерфейсі (`web_page.h`) безпосередньо під полем введення поправки додано відображення реальних вимірів датчика:
  > `Фізичний сенсор SHT30: 29.5 °C (28% RH)`
- Значення підстроювання за замовчуванням встановлено на **`-8.5 °C`**, що точно транслює внутрішній нагрів плати в зібраному корпусі (~29.5 °C) на реальну кімнатну температуру (~21.0 °C).
- Діапазон підстроювання температури розширено до `[-15.0; +10.0] °C`.
- Психрометричний розрахунок відносної вологості перераховує тиск насиченої пари від сирої температури SHT30 до скоригованої кімнатної точки.

### 4. Підвищення версій компонентів
- **ESPHome Firmware**: `v2.3.0`
- **GD32 Coprocessor Firmware**: `v1.3.3` (`0x0133`)
- **Graphic Assets Container**: 47 активних асетів (без змін)
