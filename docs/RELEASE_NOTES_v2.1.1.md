# HTRAM Release v2.1.1

## Огляд релізу (Release Overview)
Реліз `v2.1.1` додає повністю автоматизоване оновлення всієї системи в 1 клік через веб-інтерфейс (асети SPI Flash + прошивка співпроцесора GD32 + прошивка ESPHome ESP32), замінює текстовий індикатор `"!"` на векторні піктограми статусу втрати зв'язку та синхронізації часу, а також підвищує стабільність OTA-процесу.

---

## Основні зміни (Key Features & Improvements)

### 1. Автоматизоване оновлення всієї системи в 1 клік (Option B)
- **Повна тріада компонентів**: При натисканні кнопки «Оновити» веб-інтерфейс послідовно завантажує та прошиває:
  1. `flash_assets.bin` — оновлення графічних контейнерів у SPI Flash GD32;
  2. `gd32_firmware.bin` — оновлення бінарника GD32 у staging-область flash із подальшим безпечним перезавантаженням співпроцесора;
  3. `htram-standalone.bin` — фінальна OTA-прошивка ESP32 з автоматичним перезавантаженням та звуковим сигналом успіху.
- **Безпека живлення від батареї**: Якщо пристрій працює від батареї (USB вимкнено), веб-інтерфейс запитує підтвердження користувача перед запуском важкого оновлення SPI Flash.
- **Оптимізація DRAM**: Буфери для завантаження бінарників створюються динамічно у вузькому скоупі та звільняються одразу після запису блоків, запобігаючи вичерпанню пам'яті ESP32.

### 2. Векторні піктограми статусу замість знаку оклику `"!"`
- Замість грубого символу `"!"` у лівому верхньому куті екрана (`ui_pocket`) реалізовано плавні векторні 1-бітні маски, розроблені за принципом модалу клімату:
  - **`ASSET_ID_NO_NET` (45)**: Векторна піктограма відключеного Wi-Fi (`wifi-off`) з діагональним перекресленням та чітким ореолом.
  - **`ASSET_ID_NO_TIME` (46)**: Векторна піктограма пісочного годинника (⏳) для індикації очікування NTP-синхронізації часу.
- Прямий рендеринг через апаратний бліттер GD32 зі SPI Flash (`send_draw_cached_asset`) без навантаження на DRAM ESP32.
- Автоматичне очищення області при переході на модальні екрани та відновлення після повернення на циферблат.

### 3. Підвищення версій компонентів
- **ESPHome Firmware**: `v2.1.1`
- **GD32 Coprocessor Firmware**: `v1.3.1` (`0x0131`)
- **Graphic Assets Container**: 47 активних асетів (19 844 байти)
