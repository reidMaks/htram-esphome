# HTRAM Release v2.2.0

## Огляд релізу (Release Overview)
Реліз `v2.2.0` впроваджує автоматичний добовий розклад яскравості підсвічування екрана (Day/Night Schedule) із плавним переходом (smooth fading), тимчасовим ручним перевизначенням (manual override), повною інтеграцією з REST API та оновленим адаптивним веб-інтерфейсом.

---

## Основні зміни (Key Features & Improvements)

### 1. Добовий розклад яскравості дисплея (Night Mode)
- **Автоматична зміна яскравості за часом**:
  - Доба розділяється на день та ніч із окремими часовими маркерами: `night_start_time` (за замовчуванням `23:00`) та `day_start_time` (за замовчуванням `07:00`).
  - Окрема сутність для нічної яскравості: `night_brightness` (за замовчуванням `4%`, діапазон `0%`–`100%`).
  - Денна яскравість контролюється основним повзунком `screen_brightness` (за замовчуванням `100%`).
  - Тумблер активації розкладу `night_mode_enabled` (активований за замовчуванням з відновленням стану після перезавантаження).
- **Плавний перехід (Smooth Fading)**:
  - Спеціальний асинхронний скрипт `fade_backlight` змінює яскравість кроками по 100 мс протягом 3–4 секунд.
  - Запобігає різким стрибкам світла у темряві та не спамить подіями шину Home Assistant / Web UI.
- **Тимчасове ручне перевизначення (Temporary Manual Override)**:
  - Ручне регулювання повзунка яскравості (як через Web UI, так і через Home Assistant) застосовується негайно.
  - Ручне значення не скидається щохвилини; автоматичний розклад відновлює керування лише при наступному переході фази (ранок/вечір) або при синхронізації часу.
- **Безпечна ініціалізація та синхронізація**:
  - Інтегровано в арбітр подій: перевірка розкладу виконується при першій синхронізації часу через NTP (`time_synced` з пріоритетом 9) та на фінальній стадії завантаження (`on_boot`).
  - Фокусований вплив: нічний розклад регулює виключно підсвітку екрана, не зачіпаючи світлодіоди індикатора CO2 та звукові тривоги.

### 2. Веб-інтерфейс та REST API
- **Нова картка «Нічний розклад»**:
  - Інтуїтивні селектори часу (`<input type="time">`) для початку нічного та денного періодів.
  - Окремий повзунок для нічної яскравості (з можливістю виставити `0%` для повної темряви в спальні).
  - Слайдер основної яскравості також розширено до діапазону від `0%` до `100%`.
- **Розширення REST API**:
  - `GET /api/status`: повертає статус нічного режиму, поточні години та яскравість (`night_mode_enabled`, `night_brightness`, `night_start_time`, `day_start_time`).
  - `POST /api/settings`: підтримує налаштування параметрів розкладу з валідацією та збереженням у флеш-пам'ять.

### 3. Діагностика, тестування та телеметрія
- **Оновлення CLI**: утиліта `tools/device.py` тепер відображає налаштування нічного режиму у команді `status`.
- **Mock Web Bridge**: `tools/standalone_web_bridge.py` підтримує збереження та мутацію параметрів нічного режиму для швидкого UI-тестування без фізичного заліза.
- **Автоматичні тести**: додано набір перевірок REST API та валідації UI у `tests/standalone/test_m3_challenger_rest_api.py`.

### 4. Підвищення версій компонентів
- **ESPHome Firmware**: `v2.2.0`
- **GD32 Coprocessor Firmware**: `v1.3.2` (`0x0132`, без змін)
- **Graphic Assets Container**: 47 активних асетів (без змін)
