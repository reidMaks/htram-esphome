# HTRAM Release v2.2.2

## Огляд релізу (Release Overview)
Реліз `v2.2.2` присвячений комплексній ревізії та оптимізації вбудованого веб-інтерфейсу налаштувань (`web_page.h`). Інтерфейс переорієнтовано на кінцевого користувача: усунуто надлишковий внутрішній інженерний жаргон, скорочено текстові описи, покращено візуальну ієрархію та додано обов'язкове безпекове застереження щодо роботи функцій повітряної тривоги.

---

## Основні зміни (Key Features & Improvements)

### 1. Обов'язкове попередження безпеки (Safety Disclaimer)
- **Контекст**: HTRAM є побутовим допоміжним пристроєм і залежить від локальної мережі Wi-Fi, стабільності інтернет-провайдера та хмарних сервісів.
- **Впровадження**: У картці «Повітряна тривога» додано помітний інформаційний блок попередження:
  > ⚠️ **Важливо:** Не покладайтеся виключно на цей пристрій для оповіщення про небезпеку. Годинник залежить від живлення, Wi-Fi та інтернет-зв'язку. Завжди використовуйте офіційні джерела: застосунок «Повітряна тривога», сирени та канали ОВА.

### 2. Очищення від технічного жаргону
- **Повітряна тривога**: Вилучено внутрішній термін розробників *«завдяки JAAM Fusion»*. Текст замінено на лаконічне й зрозуміле пояснення: *«Сповіщення враховують загрози як для вашого району/громади, так і по всій області (дрони, ракети, тривоги)»*.
- **Погода**: Прибрано технічний коментар розробника *«Джерело: Open-Meteo API (безкоштовно, без ключів)»*.
- **Система**: Співпроцесор відображається зрозуміло для користувача: замість окремого технічного рядка `GD32 версія` виведено єдиний блок `Версія прошивки: X.Y.Z (співпроцесор: v1.3.2)`.
- **Заголовок**: Змінено технічний заголовок сторінки з `HTRAM Standalone` на лаконічний `HTRAM`.

### 3. Лаконізація інтерфейсу та поліпшення UX
- **Сенсори**: Чіткіший підпис `Якість повітря (CO2)` замість повторення `Повітря (CO2)`.
- **Пошук населеного пункту**: Спрощено підпис поля пошуку; кнопку геолокації скорочено до `Визначити локацію автоматично`; блок введення координат вручну отримав зрозумілий заголовок `Вказати координати вручну`.
- **Будильник та меморіал**: Секцію перейменовано на `Будильник та вшанування`; з підпису хвилини мовчання видалено зайві секунди (`09:00:00` → `09:00`).
- **Світлодіоди та екран**: Усунуто тавтологію у перемикачі LED-індикації CO2; для калібрування температури додано зрозуміле пояснення призначення поправки `(компенсація нагріву корпусу)`; видалено зайвий відірваний рядок про миттєве збереження.
- **Wi-Fi**: Попередження скорочено до 2 чітких і зрозумілих тез без втрати підказки про 4 кліки для виклику SoftAP.

### 4. Підвищення версій компонентів
- **ESPHome Firmware**: `v2.2.2`
- **GD32 Coprocessor Firmware**: `v1.3.2` (`0x0132`, без змін)
- **Graphic Assets Container**: 47 активних асетів (без змін)
